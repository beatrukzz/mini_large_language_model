TRAINING AND VALIDATION DATA

Split the encoded dataset into:

80% training data
20% validation data

Training data is used to teach the model.
Validation data is kept separate so I can later test how well the
model performs on data it wasn't trained on.

BLOCK SIZE

Set block_size = 8.

This means the model can use up to 8 previous tokens as context when
learning to predict the next token.

The training examples are essentially:

token 1 -> predict token 2
tokens 1-2 -> predict token 3
tokens 1-3 -> predict token 4
etc.

This teaches the language model to predict the next character from
the characters that came before it.
